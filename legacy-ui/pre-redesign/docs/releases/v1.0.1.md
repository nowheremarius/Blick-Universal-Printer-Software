**Windows** · Download `Blick.exe` below. Your scanner needs a WIA driver.

- A failed rescan keeps the previous batch. Separate files are replaced only after all new pages have been written.
- Updating a PDF now replaces the file atomically.
- If Windows text recognition hangs, Blick stops it after two minutes per page and saves the scan without recognized text.

**RU**

- При ошибке повторного сканирования предыдущая пачка остаётся на месте. Старые отдельные файлы отправляются в корзину только после записи всех новых.
- При перезаписи PDF прежний файл заменяется одной операцией.
- Если распознавание зависло, Blick прекращает ожидание через две минуты на страницу и сохраняет изображение без текстового слоя.

БЛИК — программа для сканирования

Установка / обновление:
1. Распакуйте архив поверх старой папки Blik (настройки сохранятся).
2. Дважды щёлкните «собрать.bat» — появится Blik.exe.
3. Запускайте Blik.exe.

Внешний вид:
Тёмное «жидкое стекло» в монохроме. На Windows 11 (22H2 и новее) сквозь окно видно
размытый рабочий стол; на Windows 10 окно просто тёмное матовое. Если размытия не видно —
проверьте, что включено: Параметры → Персонализация → Цвета → «Эффекты прозрачности».

Шрифт:
Блик берёт Inter или Montserrat, если они есть (установлены в Windows или лежат в папке
Blik\fonts — подойдут файлы .ttf из папки static архива с fonts.google.com), иначе Segoe UI.

Что умеет:
• Шестерёнка в шапке — язык интерфейса (русский / English) и масштаб 75–120%.
• Пресеты «Документ / Чек / Фото / Паспорт» — все настройки в один клик.
• Вкладка «Дополнительно»: объединение в PDF, улучшение документа, распознавание текста,
  деление стола на объекты, двусторонний скан вручную, серия по таймеру.
• Рамка: «Просмотр» → обведите мышкой область → сканируется только она.
• Обрезка страницы: обведите область на готовой странице → «Обрезать» (или Enter).
• Страницы внизу: крестик — удалить (файл в корзину), перетаскивание — порядок.
• История сканов — кнопка с часами слева.
• Панель справа сворачивается стрелкой (и сама — на узком окне).

Горячие клавиши:
Enter — сканировать · Ctrl+R или F5 — пересканировать последнее · Delete — удалить страницу ·
Esc — остановить серию / снять рамку.

Двусторонний вручную:
сканируйте все лицевые стороны → «К оборотным» → переверните листы и сканируйте оборотные.
Блик сам соберёт страницы по порядку (при автоподатчике учитывает перевёрнутую стопку).

Распознавание текста работает через встроенный OCR Windows. Нужен русский язык в Windows
(Параметры → Время и язык → Язык). Если его нет, распознаётся на языке системы.

Если что-то не работает — сделайте скриншот и отправьте Claude.

# Тестовая версия Blick

Рабочее окно собрано вокруг страницы. Слева находятся навигация и миниатюры, в центре — лист с инструментами масштаба, поворота и перехода между страницами, справа — параметры и сохранение. В узком окне подписи навигации сворачиваются. Колесо над миниатюрами прокручивает длинный документ.

## Изменения

| Область | Изменение |
| --- | --- |
| Окно и диалоги приложения | Непрозрачные панели, единые цвета текста, рамок, состояний и выделения. Убраны акриловый фон и захват всего окна для размытия. Диалоги выбора папки и системные сообщения обслуживает Windows. |
| Сканирование | Основные параметры представлены выпадающими списками. Доступны прежние режимы обработки, серии по таймеру, повтор скана и ручной дуплекс. |
| Устройства | Список формируется из идентификаторов WIA. Выбор действует до завершения приложения. Обновление списка и подключение выполняются на фоновом потоке. |
| Страницы | Вертикальные миниатюры с номером, удалением и перетаскиванием. Кнопки под листом позволяют перейти на соседнюю страницу. |
| Оформление | Знак с глазом и листом воспроизведён по предоставленному концепту. В assets/brand есть прозрачные SVG и PNG для обоих фонов. ICO содержит девять размеров от 16 до 256 px. |
| Ресурсы | В EXE встроены статические начертания Inter и атлас из SVG Lucide 0.468.0. Лицензии лежат рядом с исходными ресурсами. |
| Установка | Portable EXE запускается отдельно. Установщик NSIS устанавливает тестовую версию для текущего пользователя. Сканирование использует существующий профиль Blick. |

## Проверка

Интерфейс запущен через Mono WinForms. На трёх тестовых страницах проверены переход, основной и дополнительный экраны, перестроение окна, русский и английский интерфейсы, открытие истории и настроек. Проверены пять масштабов Blick от 75 до 120 процентов. Скриншоты в screenshots сделаны с тестовыми страницами из tests/WorkspaceChecks.cs. В обычной сборке эти страницы отсутствуют.

Ветка redesign содержит отдельную проверку под Windows для сборки и существующих тестов сохранения PDF, отката при ошибке повторного сканирования и тайм-аута OCR. Для аппаратной приёмки требуются WIA-сканеры. Также требуют отдельной проверки переключение между мониторами с разным DPI, качество распознавания реальных документов и установка/удаление на пользовательской системе.

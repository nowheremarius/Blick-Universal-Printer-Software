## English

The scanning workspace has a new layout. Page thumbnails appear to the left of the preview, with scan settings on the right. Open **Devices** to choose a WIA scanner. This release adds ClearType text rendering and fixes a crash when closing drop-down menus.

Download **Blick.exe** to run the app without installing it, or use **Blick-Setup.exe** to install it for your Windows account.

## Русский

Обновлён интерфейс сканирования. Миниатюры страниц находятся слева от предпросмотра, параметры сканирования — справа. В разделе «Устройства» можно выбрать WIA-сканер. Добавлено сглаживание ClearType и исправлена ошибка при закрытии выпадающих меню.

Скачайте **Blick.exe** для запуска без установки или **Blick-Setup.exe** для установки в профиль Windows.
